# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository ini
   git clone <url-repo-kamu>
2. Masuk ke folder project
   cd library-system
3. Install dependency
   composer install
4. Copy file .env
   cp .env.example .env
5. Generate application key
   php artisan key:generate
6. Sesuaikan konfigurasi database di file .env
7. Jalankan migration
   php artisan migrate
8. Jalankan server
   php artisan serve
9. Akses di browser: http://127.0.0.1:8000
